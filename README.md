# Facility-Maintenance-Request-App
Employees submit maintenance requests tickets. Facilities staff track and update requests.

# Problem Addressed
Requests are often made through emails, phone calls and word of mouth which makes it difficult to track status.

# Platform
Web based app.

# Front-End
Request submission form. Request status dashboard.

# Back-End
Database stores work order requests. Admin can update work order request status.

# Functionality
Submit work order request. View work order request status. Update work order request progress.

# Wireframes
Login page. Request form page. Dashboard page.
