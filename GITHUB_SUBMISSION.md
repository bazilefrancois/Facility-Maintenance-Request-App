# GitHub Upload and Assignment Submission

Repository: https://github.com/bazilefrancois/Facility-Maintenance-Request-App

## Upload the project using your browser (no VS Code needed)

1. Sign in to GitHub and open the repository above (or the GitHub Classroom repository specified by your instructor).
2. Choose **Add file → Upload files**. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the **repository root**. If `README.md` already exists, confirm you are updating it rather than keeping an outdated duplicate.
3. Add the `docs/` files while preserving their folder paths. GitHub's web uploader may accept folder drag-and-drop; otherwise create the files individually with **Add file → Create new file** using names like `docs/LESSON_ALIGNMENT.md`.
4. Enter a commit message such as `Add FacilityFix web app and final documentation`, then **Commit changes**.
5. Verify the repository's main page displays the new README and files.

## Publish the Wiki outline

1. Open the repository's **Wiki** tab (if enabled).
2. Choose **Create the first page** or **New Page**.
3. Use the title `FacilityFix Project Outline` and paste the content of `docs/PROJECT_OUTLINE.md`.
4. Save the page and copy its URL. If the Wiki tab is unavailable, check repository settings or ask your instructor whether a Markdown outline in `docs/` is acceptable.

## Get the README link and downloaded copy

1. Open `README.md` in the GitHub repository.
2. Copy the page URL from the address bar. It will normally resemble `https://github.com/bazilefrancois/Facility-Maintenance-Request-App/blob/main/README.md` if your branch is `main`; **verify your actual branch and URL**.
3. On the README file page, select **Raw** and save the file as `README.md`, or use the file download control when available.
4. Submit the **actual downloaded README file**, its **verified GitHub URL**, and the Wiki link as your instructor requests.
